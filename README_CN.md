# 狼人杀：AI 模拟平台

本项目是一个功能全面的、由 AI 驱动的“狼人杀”（也称为 Mafia）游戏模拟平台。它为开发和测试 AI 代理行为、博弈论策略以及在动态环境中的复杂多智能体交互提供了一个强大的平台。

该模拟平台采用清晰的架构，将核心游戏逻辑与 AI 控制器和用户界面分离，从而实现了模块化开发和测试。

## 主要功能

*   **模块化游戏引擎**：一个由状态机驱动的引擎，管理所有游戏阶段、规则和玩家互动。
*   **多样化的角色**：支持多种经典和自定义角色，每个角色都有独特的能力：
    *   **好人阵营**：村民、预言家、女巫、守卫、猎人。
    *   **坏人阵营**：狼人、黑狼王。
*   **先进的游戏流程**：
    *   **夜晚阶段**：执行秘密行动（狼人杀人、预言家查验等）。
    *   **白天阶段**：公开讨论、提名和投票处决。
    *   **警长竞选**：一个特殊的阶段，用于选举一名拥有额外投票权的游戏主持人。
    *   **复杂场景处理**：处理平票、特殊死亡条件（猎人的最后一枪）和冲突行动。
*   **AI 驱动的玩家**：
    *   集成了大型语言模型（LLM），以创建智能的、类似人类的玩家代理。
    *   每个 AI 代理都有独特的“个性”和“记忆”，影响其决策。
    *   支持针对不同语言（英语和中文）的动态提示工程。
*   **基于 Web 的用户界面**：
    *   一个实时 Web 界面，允许人类玩家加入游戏、互动和观察 AI 代理。
    *   具有动态游戏状态显示、基于角色的信息过滤和交互式控制。
*   **全面的日志记录**：生成详细的双语（中/英）游戏日志，用于分析和调试。

## 项目架构

该项目分为几个关键模块：

-   **`game/`**：核心游戏引擎。
    -   `game.py`：管理主游戏循环、玩家名册和状态转换。
    -   `states.py`：为所有游戏阶段（例如 `NightState`、`DayState`、`VoteState`）实现状态机。
    -   `player.py`：定义玩家对象、角色及其属性。
    -   `controllers.py`：玩家控制器（人类、AI 等）的抽象基类。
    -   `history.py`：管理带有可见性规则的游戏事件日志。

-   **`llm_player/`**：AI 代理实现。
    -   `controller.py`：`LLMController` 类，它使用 LLM 根据游戏状态和其角色来进行决策。
    -   `prompts/`：包含用于指导 LLM 对不同行动和语言进行推理的提示模板。

-   **`web/`**：Web 界面。
    -   `server.py`：一个 FastAPI 后端，为 UI 提供服务并处理前端和游戏引擎之间的通信。
    -   `static/`：包含用于客户端应用程序的 HTML、CSS 和 JavaScript。

-   **`simulation/`**：用于运行自动化、非交互式模拟以进行测试和数据收集的工具。

## 快速入门

### 环境要求

*   Python 3.9+
*   一个 OpenAI API 密钥（或其他兼容的 LLM API 密钥）。

### 安装

1.  **克隆仓库：**
    ```bash
    git clone <repository-url>
    cd <repository-directory>
    ```

2.  **安装依赖：**
    ```bash
    pip install -r requirements.txt
    ```

3.  **设置您的 API 密钥：**
    在根目录中创建一个 `.env` 文件，并添加您的 API 密钥：
    ```
    OPENAI_API_KEY="your-api-key-here"
    ```

### 运行模拟

**1. 运行命令行模拟：**

这将运行一个只有 AI 玩家的游戏。

```bash
python main.py
```

**2. 运行 Web 界面：**

这允许人类玩家与 AI 对手一起加入游戏。

```bash
python main_web.py
```
然后，打开您的浏览器并导航到 `http://127.0.0.1:8000`。
